## Architecture: Resource-Based Organization

### Folder Structure

```
src/api/
├── resources/
│   ├── games/
│   │   ├── games.resource.ts    # Types, DTOs, interfaces
│   │   ├── games.controller.ts  # tsoa controller (routes)
│   │   └── games.service.ts     # Business logic
│   ├── sessions/
│   │   ├── sessions.resource.ts
│   │   ├── sessions.controller.ts
│   │   └── sessions.service.ts
│   ├── moves/
│   │   ├── moves.resource.ts
│   │   ├── moves.controller.ts
│   │   └── moves.service.ts
│   └── players/
│       ├── players.resource.ts
│       ├── players.controller.ts
│       └── players.service.ts
├── shared/                      # Shared utilities only
│   ├── errors.ts
│   ├── validators.ts
│   └── middleware.ts
├── routes.ts                    # Generated by tsoa
└── swagger.json                 # Generated by tsoa
```

### Critical Rules

1. **One Controller per Resource** - Never return other resources
2. **No Cross-Resource Type Imports** - Each resource defines its own types
3. **Self-Contained Resources** - Resources are independent bounded contexts
4. **Services Handle Business Logic** - Controllers delegate to services

---

## General Principles

### RESTful Design
- Use nouns for resources, not verbs
- Use HTTP methods appropriately
- Return appropriate status codes
- Use consistent naming conventions
- Version your API

### Resource Naming
- Use plural nouns: `/games`, `/sessions`, `/moves`
- Use kebab-case for multi-word resources: `/ai-providers`
- Use hierarchical structure for relationships: `/games/{id}/sessions`

## Controller Implementation with tsoa

### Example: Games Controller

```typescript
// resources/games/games.controller.ts
import {
  Controller,
  Get,
  Post,
  Put,
  Delete,
  Route,
  Path,
  Body,
  Query,
  Tags,
  Response,
  SuccessResponse,
} from 'tsoa';
import { GameResource, CreateGameDTO, UpdateGameDTO, GameListResponse } from './games.resource';
import { GamesService } from './games.service';

@Route('api/v1/games')
@Tags('Games')
export class GamesController extends Controller {
  private gamesService = new GamesService();

  /**
   * Retrieve a list of games
   * @param page Page number for pagination
   * @param limit Number of items per page
   */
  @Get()
  @Response<{ error: string }>(500, 'Internal Server Error')
  public async getGames(
    @Query() page: number = 1,
    @Query() limit: number = 20
  ): Promise<GameListResponse> {
    return this.gamesService.listGames(page, limit);
  }

  /**
   * Get a game by ID
   * @param id Game ID
   */
  @Get('{id}')
  @Response<{ error: string }>(404, 'Game not found')
  @Response<{ error: string }>(500, 'Internal Server Error')
  public async getGame(@Path() id: string): Promise<GameResource> {
    const game = await this.gamesService.getGameById(id);

    if (!game) {
      this.setStatus(404);
      throw new Error('Game not found');
    }

    return game;
  }

  /**
   * Create a new game
   */
  @Post()
  @SuccessResponse('201', 'Created')
  @Response<{ error: string; details?: unknown }>(400, 'Validation Error')
  @Response<{ error: string }>(500, 'Internal Server Error')
  public async createGame(@Body() body: CreateGameDTO): Promise<GameResource> {
    this.setStatus(201);
    return this.gamesService.createGame(body);
  }

  /**
   * Update a game
   * @param id Game ID
   */
  @Put('{id}')
  @Response<{ error: string }>(404, 'Game not found')
  @Response<{ error: string; details?: unknown }>(400, 'Validation Error')
  public async updateGame(
    @Path() id: string,
    @Body() body: UpdateGameDTO
  ): Promise<GameResource> {
    return this.gamesService.updateGame(id, body);
  }

  /**
   * Delete a game
   * @param id Game ID
   */
  @Delete('{id}')
  @SuccessResponse('204', 'No Content')
  @Response<{ error: string }>(404, 'Game not found')
  @Response<{ error: string }>(409, 'Conflict - Game has active sessions')
  public async deleteGame(@Path() id: string): Promise<void> {
    await this.gamesService.deleteGame(id);
    this.setStatus(204);
  }
}
```

## Service Layer

### Example: Games Service

```typescript
// resources/games/games.service.ts
import { GameRepository } from '@/data/repositories/GameRepository';
import { Game } from '@/entities/Game';
import {
  GameResource,
  CreateGameDTO,
  UpdateGameDTO,
  GameListResponse,
} from './games.resource';

export class GamesService {
  private gameRepository = GameRepository;

  async listGames(page: number, limit: number): Promise<GameListResponse> {
    const [games, total] = await this.gameRepository.findAndCount({
      skip: (page - 1) * limit,
      take: limit,
      order: { createdAt: 'DESC' },
    });

    return {
      games: games.map(this.toResource),
      total,
      page,
      limit,
    };
  }

  async getGameById(id: string): Promise<GameResource | null> {
    const game = await this.gameRepository.findOne({ where: { id } });
    return game ? this.toResource(game) : null;
  }

  async createGame(dto: CreateGameDTO): Promise<GameResource> {
    const game = this.gameRepository.create({
      name: dto.name,
      rulesText: dto.rulesText,
      strategyGuide: dto.strategyGuide,
      stateSchema: dto.stateSchema,
    });

    await this.gameRepository.save(game);
    return this.toResource(game);
  }

  async updateGame(id: string, dto: UpdateGameDTO): Promise<GameResource> {
    const game = await this.gameRepository.findOne({ where: { id } });

    if (!game) {
      throw new Error('Game not found');
    }

    Object.assign(game, dto);
    await this.gameRepository.save(game);

    return this.toResource(game);
  }

  async deleteGame(id: string): Promise<void> {
    const result = await this.gameRepository.delete(id);

    if (result.affected === 0) {
      throw new Error('Game not found');
    }
  }

  /**
   * Convert entity to resource representation
   * This isolates the API layer from the data layer
   */
  private toResource(game: Game): GameResource {
    return {
      id: game.id,
      name: game.name,
      rulesText: game.rulesText,
      strategyGuide: game.strategyGuide,
      stateSchema: game.stateSchema,
      createdAt: game.createdAt.toISOString(),
      updatedAt: game.updatedAt.toISOString(),
    };
  }
}
```

## Status Codes

### Success Codes
- `200 OK` - Successful GET, PUT, PATCH
- `201 Created` - Successful POST (with Location header)
- `204 No Content` - Successful DELETE

### Client Error Codes
- `400 Bad Request` - Invalid input
- `401 Unauthorized` - Missing/invalid authentication
- `403 Forbidden` - Authenticated but not allowed
- `404 Not Found` - Resource doesn't exist
- `409 Conflict` - Resource conflict
- `422 Unprocessable Entity` - Validation errors

### Server Error Codes
- `500 Internal Server Error` - Unexpected error
- `503 Service Unavailable` - Temporary unavailability

app.use((req, res, next) => {

### JWT Tokens (Advanced)

```typescript
// Login
POST /api/v1/auth/login
{
  "username": "user",
  "password": "pass"

Response: 200 OK
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",

GET /api/v1/games

// Middleware
import jwt from 'jsonwebtoken';

app.use((req, res, next) => {
  const token = req.get('Authorization')?.replace('Bearer ', '');

  if (!token) {
    return res.status(401).json({ error: 'Token required' });
  }

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (error) {
    return res.status(401).json({ error: 'Invalid token' });
  }
});
```

## Error Handling

### Error Response Format

```typescript
interface ErrorResponse {
  error: string;           // Error type/category
  message: string;         // Human-readable message
  details?: any;           // Additional details
  timestamp: string;       // ISO 8601 timestamp
  path: string;            // Request path
  requestId?: string;      // Unique request ID
}
```

### Error Handler Middleware

```typescript
app.use((error: Error, req: Request, res: Response, next: NextFunction) => {
  const errorResponse: ErrorResponse = {
    error: error.name || 'InternalServerError',
    message: error.message,
    timestamp: new Date().toISOString(),
    path: req.path,
    requestId: req.id
  };

  if (error instanceof ValidationError) {
    return res.status(422).json({
      ...errorResponse,
      details: error.details
    });
  }

  if (error instanceof NotFoundError) {
    return res.status(404).json(errorResponse);
  }

  // Log unexpected errors
  logger.error('Unexpected error', { error, req });

  // Don't expose internal errors in production
  if (process.env.NODE_ENV === 'production') {
    errorResponse.message = 'An unexpected error occurred';
  }

  res.status(500).json(errorResponse);
});
```

## Best Practices Summary

### Architecture ✅

1. **Use tsoa** for TypeScript-first API documentation
2. **One resource per folder** - `.resource.ts`, `.controller.ts`, `.service.ts`
3. **No cross-resource imports** - Each resource is self-contained
4. **Controllers handle only their resource** - Never return other resources
5. **Services contain business logic** - Controllers delegate to services
6. **Resources define their own types** - Even for related entities

### API Design ✅

7. **Use proper HTTP methods** - GET, POST, PUT, PATCH, DELETE
8. **Return appropriate status codes** - 2xx, 4xx, 5xx
9. **Version your API** - `/api/v1/`, `/api/v2/`
10. **Use consistent naming** - Plural nouns, kebab-case
11. **Implement pagination** - For list endpoints
12. **Validate input** - All request data
13. **Handle errors gracefully** - Consistent error format
14. **Document with tsoa** - Auto-generated OpenAPI/Swagger
15. **Implement rate limiting** - Prevent abuse
16. **Use CORS properly** - Secure cross-origin requests
17. **Authenticate requests** - API keys or JWT
18. **Test thoroughly** - Unit and integration tests

### Don'ts ❌

- ❌ Don't import types from other resource folders
- ❌ Don't return other resources from a controller
- ❌ Don't create controllers that handle multiple resources
- ❌ Don't put business logic in controllers (use services)
- ❌ Don't expose database entities directly (use resource DTOs)
